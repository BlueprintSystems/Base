# Stack

- Preact as the main (and only) framework.
- Vite for bundling.
- DaisyUI for UI. Load the `daisyui` skill for anything UI-related.
- TailwindCSS when extra styling is required.

# Commands

Run from the repository root.

- Development server: `npm run -w frontend dev`
- Building: `npm run -w frontend build`
- Preview: `npm run -w frontend preview`
